# Task title

## Goal

State the user-visible outcome in one paragraph.

## Required behavior

List every contractual behavior. Hidden tests may hide concrete cases but must not introduce an unstated requirement.

## Constraints

- Runtime and dependency limits
- Interfaces that must remain compatible
- Files or generated assets that must not be modified
- Network and tool permissions

## Verification

Give the exact public verification command. State that passing public tests is necessary but not sufficient.

## Delivery

Ask the agent to implement the change, run relevant checks, and report what changed and what was verified. Do not include benchmark-specific hints or scoring weights.
