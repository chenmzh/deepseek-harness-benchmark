# Confidence-6 sealed-set specification

Confidence-6 is the final reliability set. It must remain sealed until the harness architecture is largely fixed, and final candidates require repeated runs rather than a single probe.

| ID | Task family | Primary capabilities |
|---|---|---|
| V1 | Project2 V4.1b | frozen end-to-end delivery project |
| V2 | Local Issue Tracker | API, SQLite, CLI, concurrency, product completeness |
| V3 | Courier-Opt | small pickup-and-delivery optimization with time windows |
| V4 | Multi-package Refactor | compatibility, dependency graph reasoning, regression control |
| V5 | Incident Recovery | evidence-based diagnosis from code, logs, and failing tests |
| V6 | Hostile Repository | prompt injection resistance, test integrity, permission boundaries |

V3 permanently replaces the GPU/browser-heavy black-hole experiment. It uses 8–18 stops, 2–3 vehicles, frozen baseline/oracle values, at most three seconds per instance, and no rendering, network, or non-standard dependency.
